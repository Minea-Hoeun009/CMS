# ប្រព័ន្ធគ្រប់គ្រងថ្នាក់រៀន (Classroom Management System - CMS)

ប្រព័ន្ធគ្រប់គ្រងសាលារៀន និងថ្នាក់រៀនកម្រិតបឋម និងមធ្យមសិក្សា សម្រាប់លោកគ្រូ អ្នកគ្រូ នៅព្រះរាជាណាចក្រកម្ពុជា។

---

## 🌟 មុខងារចម្បងៗ (Key Features)

1. **ផ្ទាំងគ្រប់គ្រង (Dashboard):** សង្ខេបស្ថិតិសិស្សសរុប សិស្សស្រី សិស្សក្រីក្រ អាហារូបករណ៍ វត្តមាន និងនាឡិកាឌីជីថល។
2. **គ្រប់គ្រងសិស្ស (Students CRUD):** ចុះឈ្មោះសិស្សថ្មី កែប្រែ លុប មើលព័ត៌មានលម្អិត បម្លែងថ្ងៃខែជាភាសាខ្មែរ គណនាអាយុ និង Import/Export ជា Excel (SheetJS)។
3. **ស្រង់វត្តមាន (Attendance):** តារាងស្រង់វត្តមានប្រចាំថ្ងៃ និងប្រចាំខែ (ច, អ, ព, ព្រ, សុ, ស, អា) ដោយថ្ងៃអាទិត្យ និងថ្ងៃឈប់សម្រាកត្រូវបានកំណត់ពណ៌ប្រផេះដោយស្វ័យប្រវត្តិ។
4. **បញ្ចូលពិន្ទុ និងចំណាត់ថ្នាក់ (Scores & Ranking):** គណនាពិន្ទុប្រចាំខែ ឆមាសទី១ ឆមាសទី២ ប្រចាំឆ្នាំ ចំណាត់ថ្នាក់ស្វ័យប្រវត្តិ ក្តារកិត្តិយស (Honor Board) និងព្រឹត្តិបត្រពិន្ទុផ្លូវការ។
5. **បណ្ណាល័យ និងទ្រព្យ (Library):** កត់ត្រាការខ្ចី និងប្រមូលសៀវភៅសិក្សាគោល (ភាសាខ្មែរ គណិត វិទ្យាសាស្ត្រ សង្គម)។
6. **សៀវភៅតាមដាន (Tracking Book):** ពិនិត្យ និងបោះពុម្ពសៀវភៅតាមដានការសិក្សារបស់សិស្សម្នាក់ៗ។
7. **របាយការណ៍រដ្ឋបាល (Reports):** របាយការណ៍ស្ថិតិសិស្សដើម/ចុងឆ្នាំ របាយការណ៍វត្តមាន និងទម្រង់បោះពុម្ពផ្លូវការ។
8. **ការកំណត់ (Settings):** កំណត់ឈ្មោះសាលា ឡូហ្គោ ឆ្នាំសិក្សា ព័ត៌មាននាយក និងគ្រូបង្រៀន។
9. **Cloud Sync & Offline Persistence:** ដំណើរការដោយ Firebase Firestore រួមជាមួយ Offline Persistence អាចប្រើប្រាស់បានទោះបីគ្មានអ៊ីនធឺណិត។

## 🚀 របៀបដាក់ឱ្យដំណើរការលើ GitHub និង Vercel (Deployment Guide)

### ជំហានទី ១៖ រុញកូដទៅកាន់ GitHub (Push to GitHub)
បើក Terminal ឬ PowerShell ក្នុង Folder គម្រោង រួចវាយពាក្យបញ្ជាខាងក្រោម៖
```bash
git add .
git commit -m "Enhance CMS: Fix Firebase, Vercel readiness, and Khmer calendar standards"
git push origin main
```

### ជំហានទី ២៖ ភ្ជាប់ទៅកាន់ Vercel (Deploy on Vercel)
1. ចូលទៅកាន់គេហទំព័រ [vercel.com](https://vercel.com) រួច Sign in ដោយប្រើគណនី GitHub របស់អ្នក។
2. ចុចប៊ូតុង **"Add New..."** -> **"Project"**។
3. ជ្រើសរើស Repository ឈ្មោះ `Classroom Management` (ឬឈ្មោះ Repo របស់អ្នកនៅលើ GitHub)។
4. ក្នុងទំព័រ Configure Project:
   - **Framework Preset:** ទុកជា `Other`
   - **Root Directory:** `./`
   - **Build and Output Settings:** មិនបាច់កំណត់អ្វីទេ (Zero-config static deployment)
5. ចុចប៊ូតុង **"Deploy"**។
6. រង់ចាំប្រមាណ ២០ ទៅ ៣០ វិនាទី នោះ Vercel នឹងផ្តល់ជូនអ្នកនូវ Domain ផ្ទាល់ខ្លួនភ្លាមៗ (ឧ. `https://your-cms.vercel.app`)!

## 🔐 ការគ្រប់គ្រងតួនាទី និងសិទ្ធិប្រើប្រាស់ (Role-Based Access Control)

ប្រព័ន្ធគាំទ្រតួនាទី និងសិទ្ធិមូលដ្ឋានចំនួន ៤ កម្រិតតាមស្ថាបត្យកម្ម RBAC ជំពូកទី ២៖
1. **System Administrator (អ្នកគ្រប់គ្រងប្រព័ន្ធជាន់ខ្ពស់):**
   - សិទ្ធិ៖ គ្រប់គ្រងគណនី សិទ្ធិ កាតាឡុកសាលារៀន ការកំណត់ប្រព័ន្ធ និង Backup/Audit Log ទូទាំងប្រព័ន្ធ (Full System Access)។
2. **School Administrator (អ្នកគ្រប់គ្រងសាលា):**
   - សិទ្ធិ៖ គ្រប់គ្រងព័ត៌មានសាលាខ្លួន ឆ្នាំសិក្សា ថ្នាក់រៀន សិស្ស និងរបាយការណ៍រដ្ឋបាលក្នុងសាលា។
3. **Teacher (គ្រូបង្រៀន):**
   - សិទ្ធិ៖ មើល និងគ្រប់គ្រងសិស្សក្នុងថ្នាក់ដែលបានចាត់តាំង កត់ត្រាវត្តមាន និងបញ្ចូលពិន្ទុតាមកាលវិភាគ។
4. **Report Viewer (អ្នកពិនិត្យរបាយការណ៍):**
   - សិទ្ធិ៖ មើលតែរបាយការណ៍ និងស្ថិតិដែលបានអនុញ្ញាត ដោយគ្មានសិទ្ធិកែប្រែ ឬលុបទិន្នន័យឡើយ (Read-only)។

> [!CAUTION]
> **គោលការណ៍សុវត្ថិភាពមុនដាក់ឱ្យប្រើប្រាស់ (Production Security):**
> ពាក្យសម្ងាត់លំនាំដើមទាំងអស់ត្រូវបានដកចេញពីឯកសារសាធារណៈ។ សម្រាប់បរិស្ថាន Staging និង Production អ្នកគ្រប់គ្រងសាលាត្រូវបង្កើត និងចាត់ចែងគណនីជូនលោកគ្រូអ្នកគ្រូដោយផ្ទាល់តាមរយៈផ្ទាំង **Settings -> Users Management** ដោយកំណត់ពាក្យសម្ងាត់ដែលមានសុវត្ថិភាពខ្ពស់ (អប្បបរមា ៨ តួអក្សរ មានអក្សរធំ តូច លេខ និងនិមិត្តសញ្ញា)។

## 🧪 ការធ្វើតេស្តស្វ័យប្រវត្ត (Automated Test Suite)

ប្រព័ន្ធរួមបញ្ចូលនូវឈុតតេស្តស្វ័យប្រវត្តិ (Automated Unit & Regression Tests) ដោយប្រើប្រាស់ Node.js Test Runner៖

```bash
# ដំឡើង dependencies (Zero external dependencies required)
npm test

# ឬរត់តាមប្រភេទតេស្តជាក់លាក់៖
npm run test:syntax      # ផ្ទៀងផ្ទាត់ Syntax ឯកសារ JavaScript ទាំងអស់
npm run test:rbac        # តេស្តម៉ាទ្រីសសិទ្ធិតួនាទីទាំង ៤ (Role-Based Access Matrix)
npm run test:rules       # ពិនិត្យសុវត្ថិភាព និងច្បាប់ Firestore Security Rules
npm run test:regression  # តេស្តមុខងារស្នូល (Validator, XSS, Attendance, Scores)
npm run test:backup      # តេស្តសុចរិតភាពទិន្នន័យ Backup & Restore
```
